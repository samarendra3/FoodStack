# FoodStack — REST API (v1)

Base URL: `/api/v1`. OpenAPI 3.1 generated by `@nestjs/swagger` at `/api/docs` (disabled publicly in prod; exported in CI for `packages/api-client`).

## 1. Conventions

- Auth: `Authorization: Bearer <access_token>` (staff apps). Refresh via httpOnly cookie (web) or secure storage (device).
- Tenant context comes **from the token**, never from a client header. Branch context: `X-Branch-Id` header, validated against the user's scopes (or path param where natural).
- `Idempotency-Key` header required on POSTs that create money/order records.
- Pagination: cursor-based `?limit=50&cursor=...` → `{ data, page: { nextCursor, hasMore } }`.
- Filtering/sorting: `?status=open&sort=-createdAt`.
- Money: integers in minor units + `currency`.
- Errors (RFC 9457 Problem Details):

```json
{
  "type": "https://docs.foodstack.app/errors/insufficient-permission",
  "title": "Forbidden",
  "status": 403,
  "code": "AUTH_PERMISSION_DENIED",
  "detail": "Missing permission refund:approve",
  "requestId": "01J..."
}
```

- Optimistic concurrency: `If-Match: <version>` on PATCH of master data → `409` on mismatch.

## 2. Endpoint Inventory

### Auth `/auth`

| Method     | Path                                             | Notes                                                  |
| ---------- | ------------------------------------------------ | ------------------------------------------------------ |
| POST       | `/auth/login`                                    | email/phone + password → tokens (+ `mfaRequired`)      |
| POST       | `/auth/mfa/verify`                               | TOTP/OTP                                               |
| POST       | `/auth/pin-login`                                | staff PIN on registered device (device token required) |
| POST       | `/auth/refresh`                                  | rotate refresh token                                   |
| POST       | `/auth/logout`                                   | revoke session                                         |
| POST       | `/auth/logout-all`                               | revoke all sessions                                    |
| POST       | `/auth/switch-tenant`                            | issue token for another membership                     |
| POST       | `/auth/password/forgot` · `/auth/password/reset` |                                                        |
| GET        | `/auth/me`                                       | profile, memberships, effective permissions per scope  |
| GET/DELETE | `/auth/sessions` · `/auth/sessions/:id`          | device/session management                              |

### Platform (Super Admin) `/platform`

`GET/POST /platform/tenants`, `GET/PATCH /platform/tenants/:id`, `POST /platform/tenants/:id/suspend|activate`, `POST /platform/tenants/:id/impersonate` (audited, time-boxed), `GET/POST/PATCH /platform/plans`, `GET /platform/subscriptions`, `GET /platform/metrics`, `GET/PUT /platform/feature-flags`.

### Restaurants & branches

| Method           | Path                                                                              |
| ---------------- | --------------------------------------------------------------------------------- |
| GET/POST         | `/restaurants`                                                                    |
| GET/PATCH/DELETE | `/restaurants/:id`                                                                |
| GET/PUT          | `/restaurants/:id/settings`                                                       |
| GET/POST         | `/restaurants/:id/branches`                                                       |
| GET/PATCH/DELETE | `/branches/:id`                                                                   |
| GET/PUT          | `/branches/:id/settings` (effective = merged view `?effective=true`)              |
| GET/POST/PATCH   | `/branches/:id/devices`, `/branches/:id/printers`, `/branches/:id/invoice-series` |
| GET/POST/PATCH   | `/tax-rates`, `/tax-groups`                                                       |

### Employees

`GET/POST /employees`, `GET/PATCH/DELETE /employees/:id`, `PUT /employees/:id/roles`, `PUT /employees/:id/branches`, `POST /employees/:id/reset-pin`, `GET/POST /shifts`, `POST /attendance/clock-in|clock-out`, `GET/POST/PATCH /roles` (custom roles), `GET /permissions`.

### Menu & catalog

`/categories` (CRUD + `PATCH /categories/reorder`), `/products` (CRUD, `POST /products/:id/image` → S3 presigned URL), `/products/:id/variants`, `/modifier-groups`, `/menus`, `/menus/:id/items`, `/price-lists`, `/price-lists/:id/items` (bulk PUT), `PATCH /branches/:id/availability` (86 an item), `GET /catalog/snapshot?branchId=&since=` (POS bootstrap, ETag).

### Floor

`/floors`, `/tables`, `POST /tables/:id/sessions` (open), `POST /table-sessions/:id/transfer|merge|close`, `POST /tables/:id/qr-token/rotate`.

### POS

| Method | Path                                                   | Notes                              |
| ------ | ------------------------------------------------------ | ---------------------------------- |
| POST   | `/pos/cash-drawer/open` · `/pos/cash-drawer/:id/close` | float & counted cash               |
| POST   | `/pos/cash-drawer/:id/movements`                       | pay-in/out                         |
| POST   | `/pos/checkout`                                        | order → invoice → payments, atomic |
| POST   | `/pos/day-close`                                       | Z-report                           |
| GET    | `/pos/reports/x`                                       | mid-shift X-report                 |

### Orders

`GET /orders`, `POST /orders`, `GET /orders/:id`, `POST /orders/:id/items`, `PATCH /orders/:id/items/:itemId`, `POST /orders/:id/items/:itemId/void`, `POST /orders/:id/fire` (send KOT), `POST /orders/:id/status`, `POST /orders/:id/cancel`, `POST /orders/:id/discounts`.
Kitchen: `GET /kitchen/tickets?stationId=`, `POST /kitchen/tickets/:id/status`, `POST /kitchen/tickets/:id/bump|recall`.

### Billing

`POST /invoices` (from order(s), supports split), `GET /invoices`, `GET /invoices/:id`, `GET /invoices/:id/pdf`, `POST /invoices/:id/void`, `POST /invoices/:id/credit-notes`, `GET /credit-notes/:id`, `POST /invoices/:id/send` (email/SMS/WhatsApp).

### Payments & refunds

`GET /payment-methods`, `POST /payments` (record/initiate), `GET /payments/:id`, `POST /payments/:id/capture|cancel`, `POST /webhooks/payments/:provider` (public, signature verified), `POST /payments/:id/refunds`, `GET /refunds`, `POST /refunds/:id/approve|reject`.

### Inventory, recipes, procurement

`/stock-items`, `/units`, `/warehouses`, `GET /stock-levels`, `GET /stock-ledger`, `POST /stock-adjustments`, `POST /wastage`, `/stock-transfers` (+ `/dispatch`, `/receive`), `/stock-counts` (+ `/submit`, `/approve`), `/recipes`, `/suppliers`, `/purchase-orders` (+ `/approve`, `/send`), `/goods-receipts`, `/supplier-bills`.

### Customers & loyalty

`/customers` (CRUD, `?phone=` lookup), `/customers/:id/orders`, `/customers/:id/loyalty`, `/loyalty-programs`, `POST /loyalty/redeem/quote`, `/coupons`, `POST /coupons/validate`, `/feedback`.

### Reports

`GET /reports/sales-summary`, `/reports/sales-by-item`, `/reports/sales-by-category`, `/reports/payments`, `/reports/taxes`, `/reports/discounts-voids`, `/reports/staff-performance`, `/reports/inventory-valuation`, `/reports/food-cost`, `/reports/hourly-heatmap`; `POST /reports/exports` (async → job id) → `GET /reports/exports/:id` (presigned S3 URL). Common params: `from,to,branchIds[],groupBy`.

### Subscription (tenant side)

`GET /subscription`, `GET /subscription/plans`, `POST /subscription/change-plan`, `POST /subscription/cancel`, `GET /subscription/invoices`, `GET /subscription/usage`, `POST /webhooks/billing/:provider`.

### Notifications & audit

`GET /notifications`, `POST /notifications/:id/read`, `/notification-templates`, `GET /audit-logs?entityType=&entityId=&actor=`.

### Sync (offline POS)

`GET /sync/bootstrap`, `GET /sync/changes?since=<cursor>`, `POST /sync/push` (batch of outbox ops), `GET /sync/status/:batchKey`.

### Public (customer QR) `/public`

`GET /public/tables/:qrToken` (resolve branch/table, start guest session), `GET /public/menu?session=`, `POST /public/orders`, `GET /public/orders/:id`, `POST /public/orders/:id/pay`, `POST /public/otp/send|verify`.
