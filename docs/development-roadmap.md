# FoodStack — Development Roadmap

Each phase ends with a demo-able, tested increment. Durations assume a small team (3–5 engineers).

| Phase                                | Scope                                                                                                                                                                                                                                                                                 | Duration |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| **0. Foundation**                    | Monorepo (pnpm + Turborepo), version verification & pinning, shared configs, docker-compose, NestJS core (config, logging, errors, DB, Redis, BullMQ, outbox, tenant context, RLS migration pattern), CI pipeline, design system tokens in `packages/ui`, OpenAPI → client generation | 2–3 wks  |
| **1. Identity & tenancy**            | Auth (password, MFA, refresh rotation, sessions), RBAC + scopes, tenants, restaurants, branches, settings inheritance, employees, device registration, Super Admin basics                                                                                                             | 3 wks    |
| **2. Catalog & floor**               | Categories, products, variants, modifiers, tax groups, price lists, menus, availability, image upload, floors/tables, Admin dashboard screens                                                                                                                                         | 3 wks    |
| **3. Orders, kitchen, POS (online)** | Order state machine, KOT routing, KDS app, Socket.IO, POS UI (touch), checkout → invoice → payments, cash drawer, X/Z reports, receipt printing                                                                                                                                       | 4–5 wks  |
| **4. Billing depth**                 | Invoice series, credit notes, refunds with approvals, discounts & overrides, split/merge bills, gateway integration + webhooks, reconciliation                                                                                                                                        | 3 wks    |
| **5. Offline POS**                   | PWA, IndexedDB stores, outbox, sync API, offline grant, device invoice series, conflict handling, recovery UX, chaos testing (network toggling)                                                                                                                                       | 4 wks    |
| **6. Waiter & QR apps**              | Waiter PWA, table sessions, QR tokens, public menu & ordering, guest OTP, online payment, approval flow                                                                                                                                                                               | 3 wks    |
| **7. Inventory & procurement**       | Stock items, units, warehouses, ledger, recipes, auto-deduction, wastage, counts, transfers, suppliers, POs, GRN                                                                                                                                                                      | 4 wks    |
| **8. CRM, loyalty, notifications**   | Customers, feedback, loyalty programs, coupons, templates, email/SMS/WhatsApp                                                                                                                                                                                                         | 3 wks    |
| **9. Reports & analytics**           | Aggregation jobs, dashboards (Recharts), exports, food-cost & variance                                                                                                                                                                                                                | 3 wks    |
| **10. Subscriptions & SaaS ops**     | Plans, entitlements, SaaS billing provider, dunning, usage, Super Admin completion, impersonation                                                                                                                                                                                     | 2–3 wks  |
| **11. Hardening & launch**           | Load tests, pen test, DR drill, observability dashboards, docs, onboarding wizard, pilot restaurants                                                                                                                                                                                  | 3 wks    |

MVP for pilot = Phases 0–5 (+ basic reports). Later: delivery-aggregator integrations, e-invoicing per country, multi-language, central kitchen, franchise catalog sharing, branch local relay, mobile native wrappers.
